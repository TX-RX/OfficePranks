# Contributor Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind. Pranks are about laughter, not humiliation. If a contribution targets someone's identity, beliefs, or vulnerabilities, it doesn't belong here.
- No harassment, no slurs, no doxxing, no sexual content. We're aiming for the energy of a whoopee cushion, not a hostile workplace.
- Disagreement is fine; condescension is not. Review feedback should focus on the code or the prank, never the person.
- Maintainers may remove comments, commits, issues, PRs, or contributors that violate these rules. Severe or repeated violations result in a permanent ban.

## Reporting

If you experience or witness behavior that violates this code, open a private security advisory at [github.com/TX-RX/OfficePranks/security/advisories/new](https://github.com/TX-RX/OfficePranks/security/advisories/new) or email the repository owner directly. Reports are kept confidential. We will acknowledge within 7 days and follow up with the outcome.

## Scope

This applies in all project spaces — issues, pull requests, discussions, commit messages, code comments, and any public communication tagged as representing this project.
